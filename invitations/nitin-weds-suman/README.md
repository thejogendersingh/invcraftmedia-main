# Aarav & Ananya | Wedding Invitation

A luxury seaside wedding invitation website for **Aarav & Ananya** (14 February 2026, Cavelossim Beach, South Goa).

## ✨ Features

- **Animated Video Curtain**: Fullscreen curtain reveal with sound and smooth transition.
- **Ambient Background Music**: Integrated romantic soundtrack with floating play/pause control.
- **Falling Petal Particles**: Natural flower petals scatter gracefully upon tapping the hero area.
- **Live 3D Flip Countdown Timer**: Real-time animated flip cards counting down days, hours, minutes, and seconds.
- **Interactive Sky Lanterns**: "Release lanterns" button sends 22 floating lanterns into the sky with multi-layer depth.
- **Interactive Schedule**: Detailed timeline for Haldi, Mehendi, Sangeet, Wedding, and Reception ceremonies.
- **1-Click Calendar Add**: Automatic `.ics` (iCalendar) generation and download.
- **Google Maps Navigation**: Direct link to the Sea Pearl Resort venue on Cavelossim Beach.
- **Mobile-First & Fully Responsive**: Designed for all phone, tablet, and desktop viewports.

## 🚀 Running Locally

Open `index.html` in any modern web browser or serve locally:

```bash
npx serve -l 3000 .
```
