# Shared Assets Directory
Store common brand assets here, such as:
- InvCraft Media logos (`invcraft-logo.svg`, `invcraft-logo.png`)
- Global social preview image (`invcraft-og.jpg`)
- Favicons (`favicon.ico`, `apple-touch-icon.png`)

NOTE: Do NOT put client-specific wedding assets here. Client wedding assets must always be kept inside their respective `invitations/<slug>/assets/` directory.
